Table Relationships (ERD Summary)

login 1 → N donors
One login account links to one donor profile via login_id (FK)
login 1 → N patients
One login account links to one patient profile via login_id (FK)
login 1 → N ngos
One login account links to one NGO organisation record via login_id (FK)
login 1 → N complaints
Any user can file many complaints — linked via login_id (FK)
donors 1 → N hair_donation_posts
One donor can create many hair donation posts via donor_id (FK)
hair_donation_posts 1 → N hair_requests
One donation post can receive many patient requests via post_id (FK)
patients 1 → N hair_requests
One patient can send many requests across different posts via patient_id (FK)
ngos 1 → N hair_requests
One NGO manages many requests routed through it via ngo_id (FK)
ngos 1 → N campaigns
One NGO can create many campaigns/drives via ngo_id (FK)
